# PetPawsShop
Pet Paws is an app made to allow pet owners to browse and buy pet products conveniently and accessibly. The app serves as a centralised digital storefront offering a pre-curated array of pet products. This includes food, toys, accessories, and other important care items that pet owners need on a regular basis. This can greatly reduce the time they have to spend sourcing for pet products, from one single app instead of multiple widely spread-out suppliers.
